# debacal 0.1.1

Fixes calendar discovery and server color refresh when a distribution's
python-caldav package has a missing dependency. Debacal uses its existing
read-only DAV discovery fallback; event synchronization still uses vdirsyncer.
Arch package checks now test discovery offline with the package interpreter.

This release has a new version and new archive filenames. Updating from
`0.1.0` therefore avoids checksum failures caused by cached copies of the
archive that was replaced during initial release preparation.

## Install or update

**Arch release:** extract `debacal-0.1.1-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`. It downloads and verifies the matching source archive.

**Arch checkout:** fully quit Debacal, then run from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.1/debacal-0.1.1-py3-none-any.whl
```

Restart Debacal afterwards. Existing profiles, settings and stored passwords
are retained. Python 3.11+ is required; source and SHA-256 sums are attached.
See the [installation guide](https://github.com/thobl/debacal/blob/v0.1.1/docs/INSTALL.md)
for details. Licensed under 0BSD.
