# debacal 0.1.0

First public-ready release of a local-first Linux desktop calendar.

- Day, week, month and year views; search and configurable keyboard shortcuts.
- Nextcloud/CalDAV discovery and background sync through vdirsyncer, with
  stored credentials and visual conflict resolution.
- Standard recurrence, custom event sequences, alternative time slots and
  consistent one/all/following operations.
- Previewed ICS imports, selective export, copy/paste placement and undo/redo.
- Configurable appearance, light/dark themes and isolated profiles.

## Install

**Arch:** extract `debacal-0.1.0-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -si`. The recipe fetches the matching, checksum-verified source.

**Other Linux distributions:** install pipx, then run:

```sh
pipx install https://github.com/thobl/debacal/releases/download/v0.1.0/debacal-0.1.0-py3-none-any.whl
debacal --demo
```

Python 3.11+ is required. Source and SHA-256 sums are attached too. See the
[installation guide](https://github.com/thobl/debacal/blob/v0.1.0/docs/INSTALL.md)
for desktop integration and source installation. Licensed under 0BSD.

Dependency metadata automatically avoids PySide6 6.12.0 on Python 3.11 due
to an upstream native crash; newer Python versions are unaffected by this
restriction.

This is an early release. Dense year navigation and large import commits can
still pause briefly. System-keyring integration and accessibility should be
checked on your desktop. See the
[review](https://github.com/thobl/debacal/blob/v0.1.0/docs/RELEASE_REVIEW.md)
for validation and known limits.
