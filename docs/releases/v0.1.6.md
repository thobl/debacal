# debacal 0.1.6

- Faster year views with compact daily summaries and direct counting for simple
  UTC daily rules. Other timezones and complex recurrences retain the general
  prepared-range implementation.
- Reduce repeated event copying, calendar-row updates and work when applying
  preferences. Fix a Qt layout-item lifetime failure found during long usage
  tests involving calendar reordering and removal.
- Improve iCalendar interoperability: scoped timezone definitions, negative DST,
  folded UTF-8, legacy encoded text, multiple calendar documents and compatible
  CalDAV envelopes. Conflicting or unsupported resources remain reviewable.
- Add extended local performance tests and keep large capacity workloads outside
  release CI. Include the optional pytz provider in development test coverage.

The [performance report](https://github.com/thobl/debacal/blob/v0.1.6/docs/PERFORMANCE_2026-11-16.md)
compares three versions on the same machine and includes all measured operations,
startup, memory, remaining slow cases and raw results. In the large synthetic
workload, year-view entry fell from 1,386 ms average / 1,431 ms maximum to
386 / 406 ms. Startup is essentially unchanged; search and full-calendar export
remain areas for improvement.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.

**Arch release:** extract `debacal-0.1.6-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.6/debacal-0.1.6-py3-none-any.whl
```

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
