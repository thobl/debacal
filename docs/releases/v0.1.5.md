# debacal 0.1.5

- Fix imported invitations failing to upload to CalDAV servers with HTTP 415.
  Uploads now remove the scheduling-only `METHOD` header while retaining event
  details, attendees, alarms, timezones and recurrence exceptions. This change
  is limited to CalDAV uploads.
- Identify rejected event uploads in the issues dialog, with the event title,
  date, HTTP status and options to inspect or save the attempted calendar data.
  Local events and pending changes remain safe, and successful retries clear
  their warnings.

Existing queued imports are retried automatically during synchronization; they
do not need to be imported again.

Validated with automated tests, an offline Arch package build, installed-wheel
checks and reproducible release archives.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.

**Arch release:** extract `debacal-0.1.5-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.5/debacal-0.1.5-py3-none-any.whl
```

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
