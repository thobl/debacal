# debacal 0.1.3

Unpublished: release checks found additional timezone and startup issues.
The corrected release is [v0.1.4](v0.1.4.md).

This release includes all changes since v0.1.2.

- Support producer-prefixed timezone identifiers, including libical's
  `/freeassociation.sourceforge.net/Europe/Berlin`, when no embedded definition
  is present.
- Replace date-window result caches with maintained interval indexes and
  prepared recurrence data. First visits, unrelated date jumps and calendar
  visibility changes no longer reparse unrelated event resources.
- Reduce startup work and memory use with compact persistent preparations and
  bulk construction of the in-memory indexes.
- Keep the interface responsive while sync writes to the database, including
  event changes, imports, undo/redo and source settings. Queued saves are atomic,
  report failures, preserve later navigation and finish before closing.
- Avoid reformatting unchanged search results when calendar visibility changes.

Validation: 3,885 tests and 169 subtests passed before packaging. The extracted
release passed 3,841 tests and 169 subtests, with 34 maintainer-only checks skipped.
A synthetic 4,320-resource contention check measured maximum hide/show times of 41/51 ms
while sync held the writer lock. See the
[performance report](https://github.com/thobl/debacal/blob/v0.1.3/docs/PERFORMANCE.md)
for methodology and limits.

## Install or update

Fully quit Debacal before updating. Existing profiles and stored passwords are
retained. UI settings migrate automatically into a separate file beside the
calendar database: `calendar.sqlite3.ui.sqlite3`. Back up both files with the app
closed to retain events and settings.

**Arch release:** extract `debacal-0.1.3-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`. It downloads and verifies the matching source archive.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.3/debacal-0.1.3-py3-none-any.whl
```

**Source checkout with uv:** run `uv sync --extra dev`, then
`uv run debacal --test` for the separate testing profile. The checkout environment
and system installation remain separate.

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
See the [installation guide](https://github.com/thobl/debacal/blob/v0.1.3/docs/INSTALL.md)
for details. Licensed under 0BSD.
