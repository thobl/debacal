# debacal 0.1.10

- Add saved event reminders in the event editor, including reminders before or
  after the start or end and at a fixed date and time. Recurring events support
  reminders for individual occurrences and series scopes. Saved reminders travel
  with iCalendar exports and CalDAV synchronization.
- Enable optional delivery in **Preferences → Notifications**, choosing desktop
  alerts, the in-app inbox, or both. Open, dismiss or snooze reminders from the
  inbox, and choose how missed reminders are handled. Notifications start off;
  Debacal must be running to deliver them. See
  [Using reminders](https://github.com/thobl/debacal/blob/v0.1.10/docs/NOTIFICATIONS.md).
- Set separate reminder defaults for new timed and all-day events. Import review
  can keep, remove, add missing or replace saved reminders. Under **Calendar
  sources**, use saved reminders, mute a calendar or set local reminder rules,
  including for read-only calendars.
- Optionally keep Debacal running in the system tray when closing its window,
  so reminders and synchronization continue. The tray offers **Show Debacal**
  and **Quit Debacal**; its icon follows the preference. Pending imports remain
  available for review or retry when closing or quitting.
- Keep calendar context menus accessible on read-only sources and in the
  additional calendars popup. Menus and calendar dialogs keep the popup stable.
  Both calendar editors now share a compact preset and custom color chooser.
- Choose **Uniform** or **Calendar colors** under **Preferences → Appearance → Colors**.
  Uniform colors offer brightness and intensity adjustments; calendar colors use
  the selected source colors directly, with readable text and selection cues.
- Preserve reminder timing across daylight-saving changes, recurrence edits,
  imports, undo and redo. Snooze requests revalidate the selected occurrence and
  its alarm. Background reminder work and more direct editor updates keep
  calendar interactions responsive.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.
If the window closes to the tray, use **Quit Debacal** from its tray menu.

**Arch release:** extract `debacal-0.1.10-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.10/debacal-0.1.10-py3-none-any.whl
```

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
