# debacal 0.1.4

- Use DejaVu Sans as the default typeface so system and virtual-environment
  installations have a consistent appearance. The Arch recipe installs the font.
- Fix desktop themes pinning controls to a Regular/Book face and suppressing
  bold text. Calendar selection and headings now retain their intended weights.
- Keep selected-calendar and preferences-category weights consistent across
  refreshes and focus changes.

Existing font choices are preserved. To switch an existing profile, choose
DejaVu Sans in **Preferences → Appearance → Font**. System default remains
available.

Validation: 3,933 tests and 169 subtests passed, plus extracted-source and
installed-wheel font/rendering checks. The Arch package built successfully and
release assets reproduced byte-for-byte.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.

**Arch release:** extract `debacal-0.1.4-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.4/debacal-0.1.4-py3-none-any.whl
```

For wheel/source installations, install DejaVu Sans using your distribution's
font packages if it is missing; Qt otherwise substitutes an available font.

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
