# debacal 0.1.8

- Add multiple occurrences directly in the main calendar from the event editor.
  Use the calendar-and-pointer button beside **+**, hover to preview, then click
  to add with the reference duration. Drag and resize draft dates to adjust them.
  Existing events stay read-only; nothing is saved until the editor is saved.
- Keep the editor closed during calendar picking for reliable window handling.
  **Done** or **Esc** returns to the same draft, and picking can be resumed as
  often as needed. The highlighted Done button shares the Actions toolbar row
  without moving the calendar layout.
- Preserve moved occurrences when adding another at their former time, and keep
  resized durations consistent in the editor. Background refreshes retain active
  draft drags; incoming imports wait until event editing is finished.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.

**Arch release:** extract `debacal-0.1.8-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.8/debacal-0.1.8-py3-none-any.whl
```

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
