# debacal 0.1.9

- Keep frequently used calendars in the main list and place occasional calendars
  in the **…** menu beside the Calendars heading. Choose their placement when
  adding a calendar, in Preferences → Calendar sources, or by dragging between
  the two lists. Calendar order and placement are saved per profile.
- Keep the current creation calendar in the main list, including when it belongs
  to the additional calendars menu. The eye buttons control event visibility
  separately from list placement.
- Use a compact popup anchored beneath the heading, with independent scrolling
  and stable geometry during refreshes and dragging. Hover over **…** while
  dragging to open it; drag out to expose the main list. Escape cancels a drag
  without changing the calendar's placement.
- Clarify drop prompts, empty states and tooltips, including the selected-calendar
  exception. Menu counts reflect the calendars actually available in the popup.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.

**Arch release:** extract `debacal-0.1.9-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.9/debacal-0.1.9-py3-none-any.whl
```

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
