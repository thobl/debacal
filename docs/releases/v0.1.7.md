# debacal 0.1.7

- Keep CPU-heavy calendar syncing outside the desktop interpreter, preventing
  background parsing from delaying settings and other interactions. Preserve
  conflict checks, queued changes and foreground-write priority.
- Open preferences categories when needed and avoid repeated Qt font setup.
  Large Undo/Redo availability checks run in the background.
- Skip calendar refreshes after unchanged syncs. Reduce year-view calculations,
  unnecessary interval-tree updates and upcoming-event generation.
- Add local benchmarks covering real background syncing and the complete
  publication cycle, with UTC and native X11/Berlin measurements.

In the large synthetic workload, opening settings during sync improved from
about 1.8 seconds average / 1.96 seconds maximum to 109 / 206 ms. Real bulk
updates still have a cost: publishing 1,500 changed resources reached 382 ms.
See the [performance report](https://github.com/thobl/debacal/blob/v0.1.7/docs/PERFORMANCE_2026-11-17.md)
for methods, all measurements and remaining limits.

## Install or update

Fully quit Debacal before updating. Profiles and stored passwords are retained.

**Arch release:** extract `debacal-0.1.7-arch.tar.gz`, review `PKGBUILD`, and run
`makepkg -sif`.

**Arch checkout:** from the repository root:

```sh
git pull --ff-only
cd packaging/arch
makepkg -p PKGBUILD.local -sif
```

**Other Linux distributions:** install pipx, then run:

```sh
pipx install --force https://github.com/thobl/debacal/releases/download/v0.1.7/debacal-0.1.7-py3-none-any.whl
```

Python 3.11+ is required. Source, wheel, Arch recipe and SHA-256 sums are attached.
