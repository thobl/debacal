Appearance

Single event

Choose one date in a plain month. Set the start and duration on a small vertical time strip, or use the adjacent written fields.

  • The month selects a day; it does not need an event box.
  • Time and duration stay together.
  • Series details stay out of the way while Repeat is Once.

What to assess

GestureSingle eventSeries
Click a dateChoose the event’s date.Add or remove that date’s extra occurrences. The first event remains protected.
Use the time stripClick to place the start; drag to set a time span.Click empty space to add another time on that date.
Click a time chipNo series chips are needed.The body selects that occurrence for time editing.
Click the chip’s ×No removal control is needed.Remove exactly that occurrence in one click, without selecting it first.

The × has a specific action here: it is a direct remove target on an existing time chip, rather than the old calendar marker for a skipped date. Date toggling works on all extra times on that date; the × targets only one.
